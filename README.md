# Life Tracker 📱

A modern, mobile-first personal management app built with **Progressive Web App (PWA)** capabilities and **Android (Capacitor)** native build support.

Track expenses, splits, recurring bills, warranties, loans, world clock, credentials vault, and scheduled notification reminders — all in one offline-first application with optional private **Google Drive cloud sync**.

---

## 🌟 Key Features

- **Dashboard & Budgets**: Real-time spending overview, daily averages, budget tracking with monthly overrides.
- **Splitwise Integration**: Create groups, add shared expenses, calculate exact settled balances with pairwise settlement summaries.
- **Reminders & Alerts**: Timed reminders with configurable alert styles (*Banner + Sound*, *Sound Only*, or *Banner Only*), preset tones, and custom notification audio file upload (.mp3, .wav, .ogg, .m4a). Works in browser and native Android push tray.
- **Credentials Vault**: Secure PIN-locked storage for sensitive cards and logins.
- **Fuel Log & Reports**: Log fuel fill-ups, calculate mileage, and generate PDF summary reports.
- **Dual Google Drive Sync**:
  - **Web**: Direct Google Identity Services (GIS) one-tap login.
  - **Android APK**: Chrome Custom Tabs bridge (`?auth=native`) with automatic deep-link return (`lifetracker://oauth-callback`).
- **100% Privacy**: All data is stored in your device's browser / IndexedDB storage, or in your own private Google Drive folder (`Life-Tracker`).

## 🚫 Files & Folders to NEVER Upload to GitHub

Do **NOT** upload temporary build outputs, machine-specific paths, binaries, or cache folders:
- ❌ `node_modules/` (Restored via `npm install` / `./manage.sh setup`)
- ❌ `android/gradle/wrapper/gradle-wrapper.jar` (Binary wrapper jar; auto-downloaded via `./manage.sh setup`)
- ❌ `android/app/src/main/assets/public/` (Generated web assets copy; auto-regenerated via `npm run cap:sync`)
- ❌ `android/app/src/main/assets/capacitor.config.json` & `capacitor.plugins.json` (Generated by Capacitor)
- ❌ `android/local.properties` (Machine-specific Android SDK path; auto-detected via `./manage.sh setup`)
- ❌ `android/.gradle/` & `android/.kotlin/` (Gradle daemon & Kotlin compiler caches)
- ❌ `android/build/` & `android/app/build/` (Compilation outputs & dex files)
- ❌ `dist/` (Generated web build; regenerated via `npm run build`)
- ❌ `life-tracker.apk` & `life-tracker.apk.idsig` (Generated binaries)

## 🛠️ Project Helper Script (`./manage.sh`)

A helper script [`manage.sh`](./manage.sh) is included to handle complete local cleaning before upload and one-step setup after download.

### 1. Before Uploading to GitHub (Clean Project & Strip Generated Files):
Run this in the project root to delete `node_modules/`, `gradle-wrapper.jar`, generated Capacitor assets (`android/app/src/main/assets/public/`), `android/local.properties`, temporary Gradle build caches, `dist/`, compiled APKs, and `.DS_Store` files:
```bash
./manage.sh clean
```

This strips everything down to pure source code (~3.5 MB) so you can safely upload or commit the folder to GitHub without binary jar files, bulky web asset duplicates, slow uploads, or file limit issues.

---

### 2. After Downloading on Any Computer (One-Step Setup & Install All):
When you download or clone this project onto any computer, simply open a terminal in the project directory and run:
```bash
./manage.sh setup
```

**What this automatically does:**
1. Verifies Node.js & npm are present.
2. Runs `npm install` to install all dependencies (`node_modules/`).
3. Auto-detects the Android SDK path on the machine and writes `android/local.properties`.
4. Automatically downloads `gradle-wrapper.jar` if missing.
5. Builds web assets (`dist/`) and synchronizes Capacitor (`android/app/src/main/assets/public/`).
6. Compiles and signs the Android APK (`life-tracker.apk`).
7. Makes your local environment 100% ready to run, edit, or test!

---

### 3. Rebuilding the APK Anytime:
Whenever you make edits and want a fresh Android build:
```bash
./manage.sh build
```
*(Or `npm run build:apk`)*
*(This synchronizes assets and compiles `android/app/build/outputs/apk/debug/app-debug.apk`.)*

## 🚀 How to Deploy to GitHub Pages

1. Upload the files to your GitHub repository (e.g. `manibhushan-kumar/life-tracker`).
2. Go to **Settings** &rarr; **Pages**.
3. Under **Build and deployment > Source**, select **Deploy from a branch**.
4. Select **Branch: `main`** and **Folder: `/ (root)`**, then click **Save**.
5. Your app will be live at:
   ```text
   https://<your-username>.github.io/life-tracker/
   ```

## 📱 Running on Android

### Download APK Over Local Wi-Fi:
To download the generated APK directly onto your phone:
1. Connect your laptop and phone to the same Wi-Fi.
2. Find your laptop IP (`ipconfig getifaddr en0` on macOS).
3. Start the download server:
   ```bash
   node /path/to/serve-apk.js
   ```
4. Open `http://<your-laptop-ip>:8080/` in Chrome on your Android phone and tap **Download APK**.
5. When prompted by Android, allow **"Install unknown apps"** and tap **Install**.

## 🔒 Google Drive Setup

1. Go to [Google Cloud Console](https://console.cloud.google.com/) > **APIs & Services** > **Credentials**.
2. Create an **OAuth 2.0 Client ID** (Web application).
3. Add your GitHub Pages URL under **Authorized JavaScript origins**:
   ```text
   https://<your-username>.github.io
   ```
4. Paste your Client ID into `js/config.js`:
   ```javascript
   const GOOGLE_OAUTH_CLIENT_ID = 'YOUR_CLIENT_ID_HERE.apps.googleusercontent.com';
   ```
